the whole SRS, because three feature areas remain unbuilt (REQ-017 external
bibliographic lookup, and parts of the reporting set). Passing this gate by
narrowing the SRS to what happens to be finished would make the gate worthless.

## Note on what the defects say about the testing
Thirteen defects, none of them found by the same technique:
  - one by a unit test, before the code met a database;
  - two by the first run against real Postgres, while every unit test passed;
  - seven by reading the code against a bug-class checklist, including the three
    most severe;
  - two by EXPLAIN ANALYZE, invisible in the schema and uncatchable by any
    functional test because the queries were correct, only slow.
No technique found more than half. That is the argument for four levels rather
than one, and it is the honest answer to "what did your testing miss".
